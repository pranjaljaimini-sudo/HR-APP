### [AI HR Analytics Dashboard](https://github.com/pranjaljaimini-sudo/HR-APP)
A deployed machine learning web application built to predict employee flight risk. It utilizes a Random Forest algorithm to analyze synthetic HR data, featuring a live, interactive UI hosted on the cloud.
* **Live Demo:** [Click here to use the Web App!](https://hr-app-upcuowwwxyi5nrwkenbk3f.streamlit.app/)
* **Tech Stack:** Python, Streamlit, Scikit-Learn, Pandas
